# AWS Security Reference Architecture: A deep dive into PCI DSS compliance

**Source:** 9820477afc39e54956fd4fd9dd1e38a7036b9b87
**Date:** 2026-09-14
**Tags:** compliance, pci-dss, aws-sra

AWS published an extension to the AWS Security Reference Architecture (SRA) that maps SRA account-scoping and service-configuration patterns directly to PCI DSS requirements: account/CDE boundary scoping, encryption, logging granularity, and access control layered on top of the existing AWS SRA baseline. It's aimed at security architects, compliance engineers, cloud platform teams, and QSAs/ISAs building or assessing a PCI-scoped multi-account landing zone. Actionable as a concrete architecture-to-compliance mapping for cardholder-data environments on AWS, not just a marketing announcement.

# Prowler 5.43.0

**Source:** tag:github.com,2008:Repository/66474729/5.43.0
**Date:** 2026-09-21
**Tags:** tooling, compliance, prowler

Prowler 5.43.0 replaces the FedRAMP 20x Low pilot frameworks with two 2026 Consolidated-Rules frameworks spanning AWS/Azure/GCP/Kubernetes/M365, adds seven AWS checks backing Inspector coverage, CISA KEV due-date tracking, and FIPS-policy enforcement, fixes GovCloud bootstrap failover when `PROWLER_AWS_PARTITION` is set, and moves Azure Defender/Key Vault checks to sovereign-cloud endpoints for AzureUSGovernment/AzureChinaCloud. These change both what fails a scan and where scans can run.
